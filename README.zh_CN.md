# Buzz Off

<p align="center">
  <img src="assets/images/buzzoff-community-cover-illustration.png" alt="Buzz Off 像素青蛙在月夜池塘捕蚊" width="480">
</p>

**一个像素风超声波驱蚊小工具，让青蛙把每次捕蚊都变成小小的街机时刻。**

Buzz Off 把 FoloToy AI Passport 变成一座有趣的月夜池塘。按下 **OK** 开启高频声波，绿色青蛙便会追踪蚊子、伸舌捕捉，并不断增加捕获计数；每捕到两只蚊子，还会响起一次真实牛蛙叫声。

## 怎么玩

1. 开机后欣赏 Game Boy 风格的揭幕动画和 CLOUDFINGER 签名。
2. 待机时池塘保持宁静，并播放轻快的背景旋律。
3. 按 **OK** 启动驱蚊声波和捕蚊动画。
4. 按 **UP** 或 **DOWN**，在 12、16、20 kHz 三档声音之间切换。
5. 再按一次 **OK** 停止，回到待机旋律。

蚊子、舌头、捕捉动画及计数变化只会在 Buzz Off 运行时出现。停止后，青蛙会回到干净宁静的池塘画面。

## 有趣之处

- 完整统一的日系像素掌机风格。
- 青蛙会观察、出击、咀嚼，并庆祝每次捕获。
- 使用实体按键探索三档声音模式。
- 原创待机旋律与真实牛蛙录音。
- 持续增加的捕获计数，让小工具拥有街机游戏般的个性。

Buzz Off 由 **CLOUDFINGER** 创作。青蛙、湿地场景及社区图集均为项目原创 AI 生成美术。牛蛙叫声来自[美国地质调查局](https://www.usgs.gov/media/videos/american-bullfrogs-lithobates-catebeianus)提供的公有领域录音。
